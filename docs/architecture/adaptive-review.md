# 自适应学习与复习

阶段九把“作答记录”真正用于下一轮学习决策，同时保持第一版规则简单、可解释且可测试。

## 掌握度投影

每次作答对应一条 `MasteryEvent`，当前掌握度是事件流按时间顺序投影后的结果：

| 事件 | 分数变化 |
| --- | ---: |
| 首次正确 | +0.15 |
| 补救后正确 | +0.08 |
| 错误 | -0.10 |
| 复习正确 | +0.12 |

分数始终限制在 0 到 1。用户通过
`PATCH /api/v1/study-sessions/{session_id}/attempts/{attempt_id}` 更正已保存答案时，系统会
替换对应事件并从完整事件流重新计算分数、作答次数和正确次数，而不是追加一个难以解释的
补偿值。第一版不引入 BKT。

## 自适应难度和前置补救

规则以知识点原始难度为基线：

- 掌握度低于 35%：降低一级。
- 掌握度在 35% 到 80%：保持原难度。
- 掌握度达到 80%：提高半级。
- 任一前置知识点掌握度低于 60%：目标难度不高于基线减半级，并把缺口交给补救节点。
- 最终难度限制在 1 到 5。

API 和学习会话同时返回目标难度、规则依据和前置缺口。LangGraph 的讲解与补救节点使用
目标难度；第二次错误后优先展示实际缺失的前置知识点，整个补救路径仍最多重试两次。

## FSRS 与复习队列

LLM 只负责按目标难度生成可确定性判分的复习题，FSRS 负责决定下次复习时间。没有配置
模型或模型生成失败时，系统使用规则题回退，因此复习闭环不依赖远程服务。

到期队列优先级为：

```text
priority = 逾期天数 × 10 + (1 - 掌握度) × 100 + 知识点难度 × 5
```

`GET /api/v1/reviews/due` 按该分数降序返回，并提供人类可读的排序依据。
`POST /api/v1/reviews/sessions` 为到期知识点创建独立的 `review` 会话；复习不会改写原计划项
状态。复习正确会产生 `review_correct` 事件并更新 FSRS。

错过复习后，可调用 `POST /api/v1/reviews/{knowledge_node_id}/defer` 延后 1 到 7 天。延期只
移动 `due_at`，保留 FSRS 的卡片状态和上次复习时间。

## 前端入口

`/reviews` 展示排序后的今日复习队列，支持开始复习和延后一天。学习/复习会话会展示
自适应难度变化、决策依据及前置知识缺口，便于用户理解和纠正系统决策。
